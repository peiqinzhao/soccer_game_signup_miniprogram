# 养生足球报名小程序 — 产品需求 (v0.1)

> 个人使用、后续开源。替代「奔战足球」，重点解决：认人、签到自动判迟到、罚款记录与限制报名、基金账本。

## 1. 核心概念

| 概念 | 说明 |
|---|---|
| 用户 User | 以微信 openid 唯一标识（小程序自动获得，用户无感知）。有头像、昵称，昵称自己可改。 |
| 球队 Club | **罚款、基金、管理员、成员、场地模板都挂在球队下。** 任何人都可以创建球队，创建者即 owner。一个用户可加入多个球队。 |
| 比赛 Game | 属于某个球队。只有该球队的管理员可以发起。 |
| 报名 Registration | 用户 × 比赛，记录状态、邀请人、签到信息、出勤判定。 |
| 罚款 Fine | 属于球队。一条罚款对应一场比赛里的一次迟到/未到/临时取消。 |
| 账本 Ledger | 属于球队。收入（罚款、捐款）与支出（买球等），余额 = 所有流水之和。 |

### 1.1 身份与权限

- **owner**：创建球队的人。可以增删管理员、改球队设置。
- **管理员 admin**：owner 从成员列表里指定。可以发起/编辑/取消比赛，处理罚款，记账，修改成员名字，手动修正签到。
- **成员 member**：通过点击群里的比赛卡片报名时自动加入球队，并记录「邀请人」（谁转发的卡片）。
- 管理员识别靠 openid，不需要知道微信本名：owner 在成员列表里看到「昵称 · 来自 XX 的邀请 · 头像」，点选设为管理员即可。

### 1.2 名字

- 用户第一次报名时，必须填写**昵称**（提示：“请填写群里大家认识你的名字”）。
- 用户可以随时修改自己的昵称，**管理员也可以修改成员的昵称**（防止有人填“嗯”）。
- 报名列表中，新成员会标注「新人 · 来自 XX 的邀请」。

## 2. 比赛

### 2.1 发起比赛（管理员）

字段：
- 开始时间 + **时区**（默认取发起人设备所在时区，可以手动选择，例如 America/Los_Angeles）
- 时长
- 场地：从球队场地模板中选择，或新建场地（名称、地址、经纬度、签到半径）
- 人数上限
- 备注
- **报名开放时间**（默认立即开放；可以设为定时，例如周四 20:00）
- **免责取消截止时间**（默认：比赛前一天 21:00，按比赛所在时区计算）
- **迟到宽限**（默认 10 分钟）
- **罚款金额**（默认 $5）

另外支持：
- 「保存为模板」「从模板导入」
- 编辑比赛、取消比赛

### 2.2 时间显示

- 所有时间一律按 UTC 存储，比赛额外记录它自己的时区。
- 页面上的时间**按查看者设备当前的时区显示**。如果查看者的时区和比赛时区不同，额外小字标出比赛当地时间。
- 各类规则的截止时间（免责取消、开赛前 1 小时、签到截止）都按比赛时区计算。

### 2.3 报名 / 替补 / 取消

- 报名开放前，按钮显示「X 月 X 日 20:00 开放报名」，不能点击。
- **有未付罚款的用户不能报名**，弹窗提示：“你在本球队有未付罚款 $X，请 Venmo @xxx 或现金支付给管理员，确认后即可报名。”
- 名额满后，新报名的人进入**排队替补**。
- 有人取消后，替补第一位**自动递补**，并收到微信订阅消息通知「替补成功」。
  - 用户在加入替补时，会弹出订阅授权（一次性订阅，用户需点“允许”）。
  - 如果用户没有授权，就收不到推送，只能自己打开小程序查看。
- 取消规则：

| 取消时间 | 行为 |
|---|---|
| 免责截止时间之前 | 取消后弹窗**推荐**转发到群里（可跳过），没有其他影响 |
| 免责截止时间 ～ 开赛前 1 小时 | 弹窗强提醒“请转发到群里，方便别人递补”，取消后弹出带「转发到群」按钮的提示（小程序无法用代码直接打开转发面板，需用户点一下）；**不罚款** |
| 开赛前 1 小时内 | 同上提醒，并视为**缺席 → 产生罚款**（管理员可以豁免） |

- 如果某人是在开赛前 1 小时内才被递补上的，他的「未到」不自动产生罚款（他可能根本来不及看到通知）。

### 2.4 分享

- 分享给微信好友或群，卡片标题带上状态，例如“@所有人 XX 参加该比赛”“XX 缺席该比赛”。
- 通过卡片进入的新用户，自动记录邀请人。

## 3. 签到与出勤判定

- **签到窗口**：开赛前 30 分钟到截止时间（开赛时间 + 迟到宽限）之后仍允许签到，但会被记为迟到。
- **GPS 签到**：签到时调用 `wx.getLocation`，计算与场地的距离。距离 ≤ 签到半径（默认 100m）才能签到。记录签到时间、距离和定位精度。
- **备选签到方式**：管理员在现场出示签到码（每分钟刷新），其他人扫码签到。在 GPS 接口权限没批下来，或某人定位异常时使用。
- **自动判定**：定时云函数每 5 分钟扫描一次已经过了截止时间、但还没有判定的比赛。对已报名的人：
  - 截止前签到 → 准时
  - 截止后签到 → 迟到，产生罚款
  - 没有签到 → 未到，产生罚款
- 管理员可以手动把某人改为「准时」，用来处理手机没电、GPS 漂移等情况。

## 4. 罚款

- 状态：`待处理` → `已付`（Venmo / 现金） 或 `豁免`（必须填写原因）。
- 管理员的罚款列表按比赛分组，可以勾选多人批量操作。
- 标记「已付」时，自动在账本里生成一笔收入。
- 限制报名的范围：**只在本球队内生效**。
- 用户在「我的」页面可以看到自己的罚款记录和状态。

## 5. 基金账本（替代 Google Sheet）

- **期初余额**：从现有 Google Sheet 手动录入一笔。
- **收入**：罚款到账（自动生成）、手动录入的收入（例如捐款）。
- **支出**：管理员录入金额、用途、日期，可以附一张收据图片。
- **所有成员可见**：当前余额、每一笔流水（包括哪笔罚款来自谁）。
- **只有管理员可以增加或修改流水**，每条流水都记录操作人和时间。

## 6. 删除的功能

广告、钱包、付费报名、用户保障、打赏、商务合作、联系客服、朋友圈分享、浏览记录、赛制选择（改为写在备注里）、「待定」状态。

## 7. 页面

1. **首页**：当前球队的最近比赛卡片，包含报名列表、报名/替补/取消按钮、签到按钮（签到窗口内显示）。
2. **比赛详情 / 报名详情**：已报名、替补、缺席列表，以及出勤判定结果。
3. **发起 / 编辑比赛**（管理员）
4. **罚款管理**（管理员）
5. **基金账本**
6. **我的**：头像、昵称、所在球队、我的出勤记录、我的罚款
7. **球队设置**（owner / 管理员）：成员、管理员、场地模板、默认规则、Venmo 账号

## 8. 技术方案

- 原生小程序 + TypeScript + **微信云开发**：云数据库、云函数、定时触发器、云存储。
  - 这是最便宜、最省事的方案：自建服务器的域名需要 ICP 备案，放在美国更麻烦。
- 时区换算：dayjs + utc/timezone 插件。
- 距离计算：Haversine 公式。
  - 美国境内的定位直接返回 WGS-84 坐标，不存在国内 GCJ-02 的坐标偏移问题。
- 数据库集合：`users`、`clubs`、`members`、`venues`、`games`、`registrations`、`fines`、`ledger`
- 安全：所有写操作都走云函数校验权限，客户端对数据库只有读权限，并且只能读自己所在球队的数据。
- 开源：MIT 协议。AppID 和云环境 ID 放在配置文件里，不提交。

## 9. 上线前置事项（owner 自己办）

1. 以个人主体注册小程序，并实名认证。
2. 选择服务类目（优先选可以申请 `getLocation` 的类目），并完成小程序备案。
3. 在后台「开发管理 → 接口设置」里申请 `wx.getLocation` 权限。
4. 在订阅消息模板库里选择「候补成功 / 报名成功」类模板。
5. 开通云开发环境。
